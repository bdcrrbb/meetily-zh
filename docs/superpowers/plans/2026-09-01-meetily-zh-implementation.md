## Phase M0 — Confirmation gate (M2 Air 16GB, own recordings)

### M0-a. Eval corpus (user)
10 clips (≥6 pure zh, ≥2 code-switch, ≥2 noisy/far-field; ≥3 speakers) + 3 full meetings (one ≥4 speakers) + **typed references for all 10 clips** (user transcription, reviewed once) + **RTTM-style speaker annotations for ≥6 clips covering: 2/4/6 speakers, overlap, far-field, room noise** (coarse on/off labels acceptable; this is a personal-corpus gate, not a general zh-quality claim — documented as such).
**Verify:** `evalset/manifest.json` complete; reference texts reviewed; annotations exist.

### M0-b. Bench harness — **pure Rust, end to end** (rule: no Python anywhere, incl. analysis)
- `m0/bench` = one Rust binary in the fork workspace: inference (production crate/config/VAD/threading) **and** metrics. CER via char-level Levenshtein (`strsim` or inline edit-distance — trivial, no jiwer); DER/speaker-count/boundary metrics computed from RTTM annotations by the same binary; results written as `results.json`; `results.md` generated by the binary (`--report` flag or tiny codegen step). No Python in any phase; if a gap ever appears where Rust truly can't do it, it's raised as a decision, not silently filled with a script.
- Order within M0 (dependencies, not menu):
  1. **M0-b0 Rust smoke first**: pinned compatibility set (crate + native libs + ONNX Runtime ABI + features + artifacts) in a machine-readable `compat-lock.json`; load + decode one wav through the release `.app` built from a clean location, packaged resource paths, ad-hoc signature. Fails on: missing lib, ABI mismatch, absent model, bad checksum, decode failure.
  2. **STT bench:** per clip, 3 runs, median RTF; **both Qwen3-int8 AND the fork's existing Whisper path on identical audio** (the CER comparison requires the baseline to actually run). Report: raw + normalized pooled CER, per-clip CER, total evaluated chars, paired deltas. Shared normalization policy documented (jiwer `cer`, defined zh transforms: trim spaces/punct, full→half width, case-fold for Latin); code-switch normalization rule stated. Pre-declared gate delta (below).
  3. **Thermal soak (controlled methodology):** two independent real-time audio producers feeding the production spool→queue→actor path at 1× cadence (worst case: room mode, both tracks full pipeline); timestamps = monotonic capture / enqueue / decode-start / result; ≥3 soak runs (spec's repeat rule); steady-state windows defined (first/last 5 min excluded/included); report p50/p95/p99 caption latency, max/p95 spool depth, loss count (must be 0), RSS, thermal pressure/frequency/power (`powermetrics` where available), power mode, ambient + competing processes recorded.
  4. **Diarization bench (numeric, pre-declared):** annotated clips, `num_clusters=-1`; metrics: DER/JER on annotated excerpts, speaker-count error, boundary error (tolerance ±0.5s), overlap handling; thresholds declared **before** running (see gate table). Full meetings for wall-time only (30/60/120-min synthetic concat).
- **Verify:** `m0/results.json` + generated `m0/results.md`; every number traceable to command + input manifest + build hash.

### M0-c. Gate decision — **component-specific branching** (not all-or-nothing)

| Gate component | Pass threshold (pre-declared) | On fail → matrix branch |
|---|---|---|
| STT capacity | soak p95 caption ≤ 3s, thermal RTF drift ≤ 20%, zero loss | Plan B sidecar eval |
| STT quality | pooled normalized CER(Qwen) ≤ CER(whisper) + 5 points absolute (subjective A/B secondary, non-binding) | alternative quant/model; else Qwen not default |
| STT packaging/API | M0-b0 smoke green, no native crash in benches | defer Qwen, keep existing provider |
| Diarization | DER ≤ 35% on personal corpus AND speaker-count error ≤ 1 on ≥ 5/6 annotated clips AND no garbage clustering | defer M2 diarization independently; STT path unaffected |
| License manifest | schema-validated, all fields present | informational (D1 personal) |

Each component's decision recorded separately with date + spec commit hash. A diarization failure blocks only M2's diarization tasks; an STT packaging failure blocks M1 — publish revised milestone graph per branch.

## Phase M2 — Diarization + finalize (FIRST USABLE RELEASE)

**M2-1. Diarization job module** — `spawn_blocking` semantics handled correctly: semaphore cap (concurrent diarization jobs = 1), detached results disposed, job state persisted, shutdown timeout policy, duplicate-job prevention. Blocking `process()` = bounded, abandonable, not interruptible. Verify: cancel/shutdown/reopen/repeated-abandon without resource growth or stale result application.
**M2-2. Merge module** — ASR segments × speaker turns → max-overlap attribution with **explicit `Unknown`/unattributed state** (min-overlap rule; gaps, ties, boundary-only contact, `A + B` overlap, deterministic tie-break). No forced attribution. Verify: unit tests cover all listed cases.
**M2-3. Finalize + edit preservation** — patches anchored to **canonical sample ranges + text context + stable patch IDs** (not segment ids); exact-match/split/merge/overlap/conflict behavior defined; conflicts stay visible; **user text never silently discarded**. Tests: finalize splits and merges edited provisional segments.
**M2-4. Recovery validation (moved up from M3 per spec §3A)** — corrupt artifact, missing artifact, forced termination (kill -9) → durable spool recovery lossless; crash-loop disablement. Verify: drill matrix green.
**M2-5. Voiceprint groundwork** — `speaker_profiles(space_fingerprint, embedding, …)`; **minimal enrollment path in this phase** (record 10s sample → profile) because M3 room-mic pinning depends on it; polished consent/naming/deletion UX stays in M4.
**M2-6. Attribution quality check** — attribution failure → decision path: diarization-informed re-segmentation (spec §2.3 fallback) becomes a planned task, not an afterthought.
**M2 Gate (release v0.1):** own recordings → attributed zh transcript + LAN summary; **owner acceptance scorecard (dated, signed)** + automated invariants: re-transcribe reproducible via exact command + build hash; "responsive" = UI main-thread p99 frame budget while diarization runs (measured, not felt).

## Phase M3 — Live capture (dual-track)

**M3-1. Inference actor** — queue ledger in **audio-seconds** (sample-count accounting), spool-before-enqueue transaction, replay cursor, idempotency by `(meeting, track, seq)`, duplicate-response discard, backlog scheduler; invariant: recording cannot start until provider Ready unless durable warm-up spooling active. Tests: overflow, duplicate delivery, out-of-order completion, actor restart, disk-full.
**M3-2. Phrase loop** — system track; segment machine per spec §2.2; **char-alignment stitching** task (explicit tests on overlap seams).
**M3-3. Live UI** — provisional captions; "model warming" ≠ "catching up"; **headset mic = You by source, bypassing ASR/diarization (explicit)**; system-track mute; playback warning; meeting-app allowlist hints + source metadata; **vocabulary hints where supported + capability-gap note where not**; **user locks honored in provisional→final reconcile**.
**M3-4. Room-mic mode** — both tracks full pipeline; voiceprint pinning (uses M2-5 enrollment); echo dedup heuristic + duplicate-rate threshold measured.
**M3-5. Capture recovery drills** — kill mid-recording, sleep/wake, engine/provider failover mid-recording, repeated start/stop, concurrent stop/decode, crash-loop disablement, spool replay. Drill log `docs/m3-drills.md`.
